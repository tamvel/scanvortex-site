1.General information

The GS1 ScanVortex application has been designed with a strong focus on user privacy. The author does not operate a server collecting application data. The application is free, with no ads, purchases or subscriptions. Google services are described below.

2.Data processing

All operations, including scanning, validation, and code generation, are performed entirely locally on the user's device.

Scan history: History and settings are stored locally. The author has no access to them. The application allows Android system backup; depending on device settings, data may be backed up to your Google account or transferred to another device. Uninstalling removes local application data, but may not remove system backups or exported files.

Data export: Data exported by the user (e.g., to CSV files) is saved in a location chosen by the user. Sharing passes selected files or data to the application chosen by the user. Imported images and clipboard content are analysed locally.

3.Permissions

Camera: Used solely for scanning codes. No images are recorded or transmitted.

Device storage: Used only to store data generated or exported by the user.

4.Scanning (Google ML Kit)

The application uses Google ML Kit to recognise codes from the camera and imported images. Recognition runs on the device; the application does not send images or code content to the author or Google for recognition.

The ML Kit SDK collects and sends diagnostic and usage data to Google: device and application version information, SDK installation identifiers, recognition configuration, performance metrics, events and errors. These data are used for diagnostics and usage analytics, not to display ads; transmission is encrypted using HTTPS.

ML Kit data information: https://developers.google.com/ml-kit/android-data-disclosure Google Privacy Policy: https://policies.google.com/privacy

5.Application updates (Google Play In-App Updates)

The application uses the Google Play update mechanism to check whether a newer version is available. The request is handled by the Play Store application installed on the device. No scan data and no history content is transmitted for this purpose, and neither an application installation identifier nor the advertising identifier is used. If an update is required, the update screen is displayed by the Play Store.
